## 🎨 A Short Philosophy

Most editors ask you to think in tracks. FrameForge asks you to think in layers of intention. Each clip you drop onto the canvas carries metadata about *why* it exists — a note, a mood tag, a reference frame. As your project grows, the forge remembers these intentions and surfaces them when they become relevant.

The result is an editing experience that feels less mechanical. You aren't filling in a form. You're having a conversation with your footage, and the software is the translator.

## 🔥 What's Inside the Forge

FrameForge Studio 2026 bundles a full production pipeline into a single installer:

- **Timeline Engine 3** — a magnetized, ripple-aware timeline that supports an unlimited number of video, audio, and adjustment layers.
- **Composite Node Workspace** — a high-level node graph for advanced blending, masking, and keying operations.
- **Particle Forge** — a GPU-accelerated particle simulator for smoke, sparks, debris, and stylized energy effects.
- **Grade Room** — a scopes-driven color environment with primary and secondary correction, HDR-aware tone mapping, and LUT import.
- **Audio Atelier** — multi-channel audio editing with per-clip EQ, dynamics, and a fast spectral repair brush.
- **Export Foundry** — a preset-aware render queue with hardware encoding support and batch project handling.
- **Recipe Library** — a growing set of one-click effect chains contributed by the community.

Every one of these modules shares a single undo stack, a single project file, and a single visual language. Nothing feels bolted on, because nothing was.

## ⚙️ First Launch Configuration

On the first run, FrameForge presents a short configuration wizard:

- **Workspace layout** — choose between the Classic layout (timeline on the bottom), the Cinematic layout (timeline on the top), and the Dual-Monitor layout (canvas on one screen, timeline on the other).
- **Color management** — select your display's color profile. FrameForge reads profiles installed at the system level and offers sRGB, Display P3, and Rec.709 presets.
- **Cache location** — designate a fast drive for the media cache. An SSD is strongly recommended.
- **Autosave interval** — pick how often FrameForge writes a recovery snapshot. The default is every five minutes.
- **Interface language** — select your preferred language. This can be changed at any time from the preferences panel.

When the wizard completes, you are dropped into an empty project with a sample timeline you can explore or discard.

## 🧩 Compositing Engine Overview

The compositing engine in FrameForge is built on a node model that sits underneath the timeline. Every clip you place is, in fact, a node. The timeline is simply a friendly view of that graph. Advanced users can open the node workspace and rewire connections, merge branches, and inject expressions.

Key concepts:

- **Nodes** represent operations. Sources, transforms, effects, and outputs are all nodes.
- **Connections** carry image data. They are typed, so a color node cannot accidentally be wired into an audio input.
- **Expressions** allow animated values to be driven by formulas, external data, or other node properties.
- **Groups** let you package a cluster of nodes into a reusable asset.

Because the timeline and the node graph share a single underlying model, an edit made in either view is immediately reflected in the other. There is no "switch modes" friction — you simply choose the lens that suits the task at hand.

## 🌫️ The Particle and VFX Lab

The particle simulator is one of the flagship components of FrameForge Studio 2026. It is GPU-accelerated, deterministic when seeded, and able to simulate tens of thousands of particles in real time on a modern graphics card.

Highlights include:

- **Emitter presets** for fire, smoke, sparks, dust, rain, snow, and stylized magic.
- **Force fields** including gravity, wind, turbulence, vortex, and attractors.
- **Collision** against 2D planes and imported 3D geometry.
- **Sub-emitters** that spawn new particle streams on particle death or collision.
- **Sprite and mesh rendering** with per-particle rotation, scale, and color.

The VFX lab also includes a suite of procedural generators for lightning arcs, energy shields, and stylized explosions. These can be layered with the particle system for rich, complex shots without leaving the application.

## 🎚️ Color and Grade Room

The Grade Room is where footage finds its voice. It offers:

- **Primary wheels** with independent shadows, midtones, and highlights control.
- **Curves** supporting RGB, luma, hue, and saturation axes.
- **Qualifiers** with vector and HSL modes for isolated corrections.
- **Windows** in circular, linear, polygonal, and custom shapes.
- **Tracking** attached to windows, qualifiers, and effects.
- **LUT support** with import and export.
- **Scopes** including waveform, parade, vectorscope, and histogram.

Every grade is non-destructive and stored per clip in the project file. Grades can be copied between clips, saved as presets, or exported as a LUT for use elsewhere.

## 🎧 Audio Workspace

The Audio Atelier is a full multi-track environment. Each track carries its own processing chain, and clips can host per-clip effects. The workspace offers:

- **Waveform and spectral views** with adjustable resolution.
- **Spectral repair brush** for removing clicks, hums, and wind.
- **Dynamic range tools** including compression, limiting, gating, and expansion.
- **EQ** with parametric bands and a live analyzer.
- **Dialogue auto-leveling** driven by speech detection.
- **Multichannel monitoring** for stereo and 5.1 sessions.
- **Sample-accurate editing** with sub-frame nudging.

Audio and video share the same timeline, the same undo stack, and the same project file. There is no round-tripping to a separate audio application unless you want to.

## 📁 Project Structure and Media Management

FrameForge projects are organized around a simple folder model:

- **Project Folder** — the root directory containing the project file and its associated assets.
- **Media Bin** — a logical grouping of imported files, whether they live inside the project folder or on an external drive.
- **Cache Folder** — regenerable intermediate data such as proxy files, previews, and audio waveforms.
- **Auto-Save Folder** — periodic recovery snapshots.
- **Renders Folder** — output files by default.

The application tracks every media file by its absolute path and offers a Relink dialog when files move. A "Collect Project" command can gather all media into a single portable folder for sharing.

## 🚀 Performance Tuning Cookbook

If FrameForge feels sluggish on your machine, try these adjustments:

1. **Enable proxy mode** on high-resolution footage. FrameForge generates lightweight proxies automatically and switches back to full resolution on export.
2. **Limit preview resolution** to half or quarter during complex shots.
3. **Disable real-time effects** on layers you aren't currently adjusting. A checkbox on each layer toggles this.
4. **Move the media cache** to an SSD. Cache I/O is often the bottleneck.
5. **Reduce particle counts** in preview. The final render always uses the full count.
6. **Close unused panels.** The interface is responsive, but each panel costs some rendering budget.
7. **Assign GPU acceleration** in preferences. FrameForge supports hardware decoding and encoding on modern GPUs.
8. **Defragment** your project drive periodically if it is a traditional hard disk.

The application includes a built-in Performance Monitor panel that graphs CPU, GPU, memory, and disk activity live. Use it to identify bottlenecks before adjusting settings blindly.

## ❓ Frequently Asked Questions

**Is FrameForge compatible with my existing project files?**
FrameForge Studio 2026 can import projects from earlier FrameForge versions and exchange files with several common interchange formats. Direct import of third-party proprietary project files is limited to documented formats.

**Can I run FrameForge on a laptop?**
Yes. The application scales to modest hardware. A dedicated GPU is recommended for heavy compositing, but the timeline and audio workspace run comfortably on integrated graphics.

**How often are updates released?**
Point releases arrive roughly every six to eight weeks. Major feature releases arrive annually. All updates are incremental and preserve project compatibility.

**Does the installer require an internet connection?**
No. The installer is self-contained. Internet access is used only for optional features like the translation portal and the community recipe exchange.
